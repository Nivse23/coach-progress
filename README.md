# Coach Progress — Telegram Mini App для фитнес-тренера

Dark Premium Fitness: тёмный графит + лаймовый акцент (по дизайн-брифу `Coach_Progress_Design_Brief.pdf`).

## Что уже есть — кабинет тренера

- **Главный экран:** число учеников, активные за 7 дней, обновления за неделю, быстрые действия,
  лента последних обновлений, список учеников со статусом активности
- **Карточка ученика:** вес, изменение с начала, рост, целевой вес
  - Тренировки — дата (по умолчанию сегодня), упражнения из каталога, подходы «вес × повторы»,
    подсказка «прошлый раз», повтор прошлой тренировки, график прогресса упражнения (вес и повторы)
  - Вес — график с периодами (1/3/6 мес / всё) и изменение за период
  - Замеры — грудь, талия, живот, бёдра, бедро, голень, бицепс, шея, % жира; таблица «было → сейчас»
  - Фото — по датам, сравнение «до/после» рядом
  - Профиль — контакты, цель, заметки
- **Упражнения:** 14 групп мышц, ~130 упражнений, поиск, свои упражнения

- **Совместная тренировка:** несколько учеников на одном экране
- **Выгрузка в Excel:** кнопка в карточке ученика. Листы: Профиль, Тренировки (каждый подход),
  Прогресс (макс. вес/повторы по датам), Вес, Замеры

Данные сейчас хранятся **на устройстве** (IndexedDB внутри Telegram).

## Публикация

1. **GitHub:** репозиторий `coach-progress` (публичный — так GitHub Pages бесплатный; в коде нет ни данных, ни секретов).
   Settings → Pages → Source: **GitHub Actions**.
   Settings → Secrets and variables → Actions → **Variables**: `ALLOWED_IDS` = ваш Telegram ID.
   Адрес приложения: `https://<логин>.github.io/coach-progress/`
2. **Бот:** @BotFather → `/newbot` → токен (никому не показывать).
   `/mybots` → бот → Bot Settings → Configure Mini App → Enable → адрес приложения.
3. **Ваш Telegram ID:** откройте приложение в боте — экран «Доступ не настроен» покажет ID
   (или @userinfobot). Впишите его в `ALLOWED_IDS` и перезапустите публикацию (Actions → Run workflow).
4. **Отправка Excel через бота:** см. раздел ниже; адрес воркера — в переменную `FILE_RELAY_URL`.

## Защита

- Вход только внутри Telegram и только для ID из `ALLOWED_IDS`; остальные видят «Нет доступа».
- Данные лежат только на вашем телефоне — по ссылке их получить нельзя.
- Сайт закрыт от поисковиков (`noindex`, `robots.txt`).
- Отправка файлов: подпись Telegram проверяется на сервере токеном бота; файл уходит только вам.

## Отправка файлов через бота (`worker/`)

Внутри Telegram на телефоне обычное скачивание не работает, поэтому Excel-файл присылает бот —
в чат с ним, откуда файл можно сохранить в память телефона или переслать.
Посредник — Cloudflare Worker (бесплатно, 100 000 запросов в сутки). Он проверяет подпись Telegram
(запрос точно от вашего аккаунта) и список разрешённых ID; токен бота хранится только в Cloudflare.

```
cd worker
npx wrangler login
npx wrangler secret put BOT_TOKEN      # токен от @BotFather
npx wrangler secret put ALLOWED_IDS    # ваш Telegram ID
npx wrangler deploy
```
Адрес воркера указывается при сборке приложения: `VITE_FILE_RELAY_URL=https://coach-progress-files.<имя>.workers.dev`.
Пока он не указан, используется меню «Поделиться» телефона, а на компьютере — обычное скачивание.
